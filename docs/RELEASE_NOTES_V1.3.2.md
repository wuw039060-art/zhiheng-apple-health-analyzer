# 知衡健康 v1.3.2

隐私优先的 Apple 健康本地分析 Windows 桌面应用。

## 主要能力

- 在本机流式解析 Apple 健康 ZIP / `export.xml`；
- SQLite 事务写入和稳定指纹去重，支持重复导入完整快照；
- 每日、洞察、建议、数据和设置五个桌面工作区；
- 7/30/90/180/365 天趋势与个人滚动基线；
- 睡眠、心率、HRV、活动、呼吸、血氧和腕温的跨指标解释；
- 本地 CSV 导出和按日期、指标或全部数据删除。

## 安装

下载 `ZhiHeng-Health_1.3.2_Windows_x64_Offline_Setup.exe` 后双击安装。安装包内置 WebView2 离线运行时，不要求用户安装 Node.js 或 Rust。

当前安装包没有商业代码签名，Windows SmartScreen 可能显示“未知发布者”。

## 安全边界

本软件用于整理个人趋势，不提供医学诊断。健康数据默认只保存在本机；仓库和 Release 不包含任何真实用户健康导出。

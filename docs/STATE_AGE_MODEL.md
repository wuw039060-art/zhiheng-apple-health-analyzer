# 状态年龄模型说明（state-age-1.0.0）

## 结论先行

“状态年龄”是一个可解释的近期体能与恢复指数，不是医学上的生物学年龄、器官年龄、寿命预测或疾病诊断。结果显示到小数点后一位，是为了让同一用户定期导入后能看到细微方向变化；它不意味着医学误差只有 0.1 岁。

软件必须同时显示点估计、合理波动区间、数据覆盖、每项贡献和模型版本。缺少近 30 天至少 3 个 VO₂ max 样本、年龄、生理性别或 14 个完整日时不出年龄。

## 计算框架

```text
状态年龄 = FRIEND 心肺适能年龄
         + 活动修正
         + 睡眠修正
         + 运动后心率恢复修正
         + 静息心率/HRV 相对个人基线修正
         + 多生命体征稳定性修正
```

所有修正合计限制在 -3.0 至 +3.0 岁。日照、活动能量、静息能量只展示背景，不直接加减年龄。

## 主锚点：VO₂ max 心肺适能年龄

使用 FRIEND Registry 心肺运动试验的同性别、分年龄段 VO₂ max 中位数。模型在相邻十年中位点之间做线性插值，输出 20–89 岁范围的“心肺适能年龄”。

男性中位数（ml/kg/min）：20–29 岁 46.5、30–39 岁 39.7、40–49 岁 35.3、50–59 岁 29.2、60–69 岁 24.6、70–79 岁 20.6、80–89 岁 17.6。

女性中位数：36.6、28.3、25.7、22.9、19.6、17.2、15.4。

Apple 白皮书报告 Apple Watch VO₂ max 与参照测试之间存在明显个体误差，验证结果约为 1.4 ± 4.7 ml/kg/min。因此区间使用 VO₂ max ±4.7 重新映射，再加入覆盖惩罚；即使点估计显示到 0.1 岁，区间仍可能很宽。

## 修正项与保护栏

| 组件 | 最大年龄影响 | 规则和边界 |
| --- | ---: | --- |
| 活动与运动 | ±1.2 岁 | 以每周 150–300 分钟成人活动建议为参考，并结合步数方向；不把 Apple Exercise 分钟当作临床运动处方。封顶防止与 VO₂ max 重复计分。 |
| 睡眠恢复 | 0 至 +2.0 岁 | 主要反映近 30 天睡眠不足的当前恢复负担，不把短睡眠换算成寿命。 |
| 一分钟心率恢复 | -0.5 至 +0.8 岁 | 近 60 天至少 3 个样本才参与。Cole 等研究的 12 bpm 阈值与具体运动/恢复方案有关，不能作为所有 Apple 训练的通用诊断线。 |
| 静息心率与 HRV | -0.5 至 +0.8 岁 | 只比较本人近 14 天与前 28 天。Apple Watch 短时 SDNN 不直接套用 24 小时 Holter 人群年龄表。 |
| 血氧、呼吸、腕温 | 0 或 +0.5 岁 | 近 14 天至少 3 天出现两项以上同步偏离个人基线才小幅修正；同时进入异常原因交叉验证。 |
| 日照与能量 | 0 岁 | 只作为作息、户外活动和负荷背景；没有可靠的人群“分钟/千卡到年龄”换算。 |

## 合成示例

以下数字仅用于解释计算流程，不来自真实用户：

- 构造 30 个完整日，并提供满足最低数量要求的 VO₂ max 样本；
- 根据构造的年龄与生理性别，在 FRIEND 曲线上插值得到心肺适能年龄；
- 活动、睡眠和恢复数据分别触发受限修正，全部修正之和仍限制在 -3.0 至 +3.0 岁；
- 缺少一分钟心率恢复样本时，该项保持 0.0 岁并降低把握度；
- 血氧、腕温、日照、活动能量和静息能量不直接换算年龄。

公开示例只验证计算方向、封顶规则和缺失数据行为，不发布个人试算结果。

## 数据质量与显示规范

- 点估计统一四舍五入到 0.1 岁，所有贡献显示到 0.1 岁。
- 始终显示区间，不能只显示一个大号年龄。
- 显示最近样本日期、有效日数、缺失数据和模型版本。
- VO₂ max 缺失或过期时停止出年龄，不用 HRV、静息心率或血氧替代猜测。
- 精确出生日期只在导入内存中用于计算当前年龄，数据库只保存年龄数值和生理性别，不保存出生日期。
- 模型升级后必须更改版本，并保留旧结果的算法版本信息。
